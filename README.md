## 📖 Sobre o Projeto

O **Jokenpô** é uma versão interativa e temática do clássico jogo "Pedra, Papel e Tesoura". Com uma interface imersiva inspirada no universo de cassinos e luzes vibrantes, o objetivo do projeto foi aplicar lógica de programação com JavaScript puro, manipulação do DOM e estilização avançada para criar uma experiência divertida e dinâmica.

---

## 🎨 Layout e Funcionalidades

- **Tema Imersivo:** Interface visual customizada com temática de cassino.
- **Placar Dinâmico:** Computador vs. Jogador atualizado em tempo real a cada rodada.
- **Feedback Visual:** Mensagens de vitória, derrota ou empate estilizadas na tela.
- **Interatividade:** Botões responsivos para a escolha da jogada (Pedra, Papel ou Tesoura).

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout responsivo e efeitos visuais.
- **JavaScript (ES6+):** Lógica do jogo, controle de pontuação e interatividade no DOM.
